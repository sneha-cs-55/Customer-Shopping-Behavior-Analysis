# Customer-Shopping-Behavior-Analysis
A data analytics project exploring 3,900+ customer transactions to uncover spending patterns, product preferences, and high‑value customer segments using Python, SQL, PostgreSQL, and Power BI
📌 Project Overview
This project analyzes 3,900+ customer transactions to uncover insights into shopping behavior, spending patterns, product preferences, and customer segments. The goal is to support data‑driven decisions for marketing, pricing, and product strategy.

📊 Dataset Description
3,900 rows

18 columns

Includes demographics, purchase behavior, product attributes, subscription status, shipping type, and discount usage.

🛠️ Tools & Technologies
Python (pandas, NumPy, matplotlib, seaborn)

SQL & PostgreSQL

Power BI

Excel

🔍 Key Steps Performed
Data cleaning (missing values, outliers, formatting)

Exploratory Data Analysis (EDA)

Feature engineering

SQL‑based querying for segmentation

Power BI dashboard creation

📈 Visualizations / Dashboard
Include:

Revenue by category

Age‑wise spending

Subscription vs. non‑subscription behavior

Discount dependency

Shipping trends

💡 Key Insights
High‑revenue customers are typically 25–40 years old.

Subscription users spend more and purchase more frequently.

Certain product categories show strong seasonal demand.

Discount‑dependent customers show lower average order value.
